# Repository Agent Instructions

These instructions apply to this repository.

## Benchmark Entries

When asked to take part in the one-button game benchmark:

- Work only inside the assigned entry directory unless the user explicitly asks for repository-level changes.
- Do not inspect, read, summarize, or copy from other model entry directories.
- Use only the benchmark prompt, top-level repository instructions, and the entry's assigned directory as context.
- Keep the submission self-contained and static so it can run from the entry directory's `index.html`.
