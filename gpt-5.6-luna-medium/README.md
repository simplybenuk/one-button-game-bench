# ECHO//DIVE

ECHO//DIVE is a neon, one-button arcade game about threading a living signal through an endless field of gates. The ship is always moving; the player’s timing determines which side of its gravity arc it travels on.

Press **Space**, tap anywhere, or click anywhere to flip the ship’s gravity. Threading a gate builds a combo and earns more points. Touching a gate or the edge of the signal field ends the run. Use the same control to restart.

The game is a self-contained static website. Open `index.html` directly or host the directory on GitHub Pages.
