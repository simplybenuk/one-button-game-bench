# Dead Air Relay

Dead Air Relay is a one-button orbital timing game. A signal craft circles each beacon while the next relay waits across the void. The route grows faster and fills with carrier-burn hazards.

Press `Space`, click, or tap anywhere to release the craft along its tangent. While it is flying, use the same control once to ping and bend its course toward the next beacon.

Catch as many beacons as possible. Centered catches and unused pings earn more points. Missing a beacon or touching a red carrier-burn field ends the transmission. Press the same control to restart.
