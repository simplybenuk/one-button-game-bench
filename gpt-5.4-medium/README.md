# Signal Bloom

`Signal Bloom` is a one-button survival game built for the One Button Game Bench.

You control a glowing seed climbing a living vine. Every tap, click, or press of `Space` switches the seed from one side of the vine to the other.

The goal is to stay alive, dodge the thorns, collect sparks, and build score through tight timing and longer combo chains.

## Controls

- `Space` on desktop
- Tap anywhere on mobile
- Click anywhere with a mouse

All three inputs do the same thing: switch sides.

## Files

- `index.html` boots the game
- `styles.css` handles layout and visual style
- `game.js` contains the game loop, input handling, rendering, scoring, and restart flow
